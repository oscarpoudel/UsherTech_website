UsherScan (UScan) is an advanced AI crack segmentation scanner built with Flutter and YOLO on-device inference for real-time concrete and structural crack detection.

## Features

- Real-time camera scanning with live YOLO instance segmentation of cracks
- On-device AI via TensorFlow Lite; runs fully offline
- Batch image processing for multiple photos at once
- Adjustable segmentation controls: mask opacity, thickness, confidence threshold, colors, background blur
- Voice feedback with text-to-speech announcements
- Scan session library with original images, processed results, and metadata
- Dark cyberpunk UI with blue neon accents
