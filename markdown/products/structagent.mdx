StructAgent is a Flask-based structural analysis assistant that combines conversational AI agent workflows, an interactive browser-based 3D modeling canvas, deterministic engineering tools, and OpenSeesPy.

## Supported analysis

- Preliminary elastic beam analysis
- Truss analysis
- 2D frame analysis
- Column buckling
- 3D space-frame analysis

All available through a chat interface and an interactive 3D canvas. Intended for research, education, experimentation, and early-stage engineering assistance. Not a substitute for review by a licensed professional engineer.
