SHM Edge Sensor and Alerting Kit is a prototype oriented monitoring system for bridges, buildings, and slabs, combining sensing, data acquisition, and a simple dashboard. It supports baseline capture, ongoing measurements, filtering and event detection, and alert thresholds. The deliverable is a practical package that demonstrates end to end capability from hardware to analytics to reporting.
